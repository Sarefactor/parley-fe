# parley-fe

[![Website](https://img.shields.io/badge/Website-parleymaf.dev-orange)](https://parley-maf.dev)
[![License](https://img.shields.io/badge/License-MIT-orange)](LICENSE)

Parley FE is a project built using SvelteKit and Svelte Flow.

It provides a canvas on which workflows are assembled from a collection of nodes which are connected via rule based transitions and configured through per-node option modals.

The main repository can be found [here](https://github.com/Sarefactor/parley), please see the [documentation](https://parley-maf.dev/) for more detail.
